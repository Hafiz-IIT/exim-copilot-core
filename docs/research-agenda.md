# Research agenda

## Question
**Can explicit evidence states and escalation logic reduce premature automation in document-heavy EXIM workflows?**

## Hypotheses
### H1
Explicit missing-evidence states reduce premature ACT decisions.

### H2
Risk-conditioned discrepancy escalation better separates routine verification from high-consequence review.

### H3
Audit events make post-hoc failure analysis easier than stateless assistant output.

## Experiments
1. Generate 1,000 synthetic cases across completeness/risk/discrepancy regimes and compare recommendation distributions.
2. Inject ordering changes and repeated corrections to test whether case history remains interpretable.
3. Measure reviewer effort with compact evidence packets versus raw event/document lists.

## Metrics
- premature ACT rate
- verification/escalation rate
- missing-evidence detection
- audit completeness
- review packet size
